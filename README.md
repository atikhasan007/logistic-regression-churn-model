# Churn Prediction Web App 📊

A **Streamlit web application** for predicting customer churn using a **Logistic Regression model**.  
The app not only predicts whether a customer is likely to churn but also provides **tips for churn prevention** and **customer retention**.

---

## Features

- Predicts if a customer is likely to churn (Yes/No)
- Interactive Streamlit interface with user input fields
- Provides **top 10 tips for churn prevention** if the customer is likely to churn
- Provides **top 10 tips for customer retention** if the customer is not likely to churn
- Scales and encodes user input before prediction

---

## Prerequisites

- Python 3.8+
- Streamlit
- Pandas, NumPy
- Scikit-learn
- Pickle
